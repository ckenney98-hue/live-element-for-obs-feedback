# Live Element for OBS: feedback & support

**Live Element for OBS** is a Chrome extension that turns any part of a web page into a live OBS overlay (now playing, chat, scores), with one click into your scene and the tab's audio.

This repository holds **feedback, bug reports and feature requests** only; the extension's code isn't here.

- **Found a problem?** [Report a problem](../../issues/new?template=bug_report.yml)
- **Have an idea?** [Request a feature](../../issues/new?template=feature_request.yml)
- **Privacy policy:** [PRIVACY.md](PRIVACY.md)

Pro and trial users can also open these forms from the extension popup (**Feedback**), with the version filled in for you.

Issues here are public. Please don't post passwords, OBS links (they contain your OBS WebSocket password) or private page addresses.
